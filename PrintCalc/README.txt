Как использовать:
1. Создай проект WPF (.NET 8) с именем PrintCalc, поставь NuGet: Microsoft.Data.Sqlite и MaterialDesignThemes.
2. Распакуй архив в папку проекта (где лежит PrintCalc.csproj) с заменой файлов.
3. В Visual Studio: правый клик по проекту -> Добавить -> Существующий элемент, выбери папки Models, Data, Views
   (если файлы не появились в Обозревателе решений; в SDK-проектах они обычно подхватываются сами).
4. .gitignore положи в корень репозитория.
